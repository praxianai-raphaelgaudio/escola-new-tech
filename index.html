API da Escola New Tech

Documentação · versão 2026.2 · somente leitura

A Escola New Tech é fictícia. Esta API existe apenas para os exercícios do Green Belt. É um conjunto de arquivos JSON estáticos: aceita apenas GET e não exige chave.

Endereço base

Todas as rotas abaixo são relativas ao endereço desta página. Exemplo: se esta página está em https://exemplo.github.io/escola-new-tech/, o catálogo está em https://exemplo.github.io/escola-new-tech/catalogo.json.

Rotas

GET/catalogo.json

Devolve a lista de todos os cursos. 200 com uma lista (array) de objetos de curso.

GET/cursos/{codigo}.json

Devolve um curso pelo código, por exemplo /cursos/NT-102.json. 200 com um objeto de curso; 404 se o código não existir.

GET/politicas.json

Devolve as políticas de pagamento, descontos, reembolso, matrícula e certificado em formato estruturado. 200 com um objeto.

Objeto de curso

CampoTipoDescrição
codigotextoCódigo do curso, no formato NT-000.
nometextoNome do curso.
areatextoProgramação, Dados, Inteligência Artificial, Design, Segurança ou Gestão.
niveltextoIniciante ou Intermediário.
modalidadetextoEx.: Online ao vivo, Híbrido, Presencial (São Paulo).
carga_horariainteiroHoras totais do curso.
duracao_semanasinteiroDuração em semanas.
precodecimalPreço de tabela, em reais.
prerequisitotextoTexto livre; "Nenhum" quando não há.
proxima_turmatextoData no formato AAAA-MM-DD, ou "Início imediato" para cursos gravados.

{
  "codigo": "NT-102",
  "nome": "Python para Iniciantes",

  "nivel": "Iniciante",
  "modalidade": "Online ao vivo",

  "prerequisito": "NT-101 ou noções de lógica",
